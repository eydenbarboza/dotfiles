# dotfiles

My configurations and automation scripts to set up a new machine.

## macOS Setup

The script `macos/install-macos.sh` automates the initial configuration of a macOS environment.

### Usage

Run the installation script:

```bash
cd ~/dotfiles
bash macos/install-macos.sh
```
